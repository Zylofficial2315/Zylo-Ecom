# ZYLO MVP — starter prototype

A mobile-friendly static shopping-discovery prototype using HTML, CSS and vanilla JavaScript.

## Run locally
1. Download and unzip the project.
2. Open the `zylo_mvp` folder.
3. Open `index.html` in a browser.

For a local development server, VS Code users can install the Live Server extension and choose **Open with Live Server**.

## Important demo limitations
- All products, prices and emoji artwork are illustrative placeholders.
- No live Meesho catalogue, affiliate tracking or checkout is connected.
- The assistant is a basic category/budget filter, not a real AI model.
- Replace placeholders only with product details, images and affiliate URLs you are authorised to use.
- Add a working contact address and review privacy, terms and affiliate disclosure before public launch.

## Files
- `index.html` — page structure
- `style.css` — responsive design
- `products.js` — sample catalogue
- `script.js` — search, category filters and demo assistant
